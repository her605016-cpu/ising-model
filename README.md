# ising-model# 2D Ising Model

A Python simulation of tiny magnets (spins) on a 10x10 grid, using the Metropolis algorithm.

At low temperature the spins line up, so the magnetization is close to 1. Near T = 2.3 the magnetization drops quickly. The exact critical temperature is 2.269.

How to run: open Ising_beginner.py in Google Colab and run it.

What I learned: [learned how the Metropolis rule uses probability to decide whether a spin flips].
