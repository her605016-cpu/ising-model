 # 2D Ising Model

A Python simulation of tiny magnets (spins) on a 10x10 grid, using the Metropolis algorithm.

At low temperature the spins line up, so the magnetization is close to 1. As the temperature rises the magnetization falls, fastest around T = 2.0 to 2.3, near the exact critical temperature of 2.269. At high temperature the spins are mixed and the magnetization is small. The grid is small (10x10), so the drop is smooth.

How to run: open Ising_beginner.py in Google Colab and run it.

What I learned: I learned how the Metropolis rule uses probability to decide whether a spin flips.
